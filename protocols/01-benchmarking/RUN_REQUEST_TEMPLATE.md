# Run Request Template

Usar esta plantilla para iniciar una nueva investigación.

```text
Aplica el protocolo definido en MASTER_PROTOCOL.md al siguiente caso.

RUBRO / DOMINIO:
<describir rubro>

MODELOS:
- ORCHESTRATOR_MODEL: <modelA>
- ADVERSARIAL_MODEL: <modelB>

MERCADO OBJETIVO (obligatorio; se registra en market de run.yaml):
<país, región o conjunto de mercados; precisar jurisdicciones, sin default>

ALCANCE DEL PRODUCTO:
Combinación potencial de sitio institucional, aplicaciones internas/backoffice, portal de clientes, ecommerce, marketplace, SaaS u otras superficies digitales que la investigación determine como relevantes.

CONTEXTO DEL PROYECTO:
<opcional: cliente, restricciones, ideas iniciales, legacy, presupuesto, stack preferido, etc.>

RESTRICCIONES / EXCLUSIONES:
<opcional>

PREGUNTAS QUE QUIERO RESPONDER:
<opcional>

INSTRUCCIÓN ESPECIAL:
Cualquier agente o subagente puede hacerme preguntas antes de continuar si detecta ambigüedades materiales. Agrupa las preguntas y explica brevemente por qué cada una puede cambiar el resultado.
Si falta el mercado o hay conflicto, pregunta y espera antes del research;
no asumas Argentina/LatAm. Usa templates/run.yaml como metadata canónica.
```
